# reactorcity

夜の円形工業都市を、約10秒のカメラワークで見渡すWebGL作品です。巨大プレート、8基の炉、中央塔、街の窓明かり、煙をコードで描画します。

## オフラインで開く

1. `index.html`をダウンロードします（GitHubのファイル表示ページではなく、HTML本体を保存してください）。
2. PCのEdgeやChromeなど、WebGL対応ブラウザーで開きます。

HTML・CSS・JavaScript・描画用シェーダー・環境音の生成処理を単一ファイルに含みます。ビルド、インストール、外部CDN、APIキー、外部通信は不要です。

iPhoneのChatGPTアプリ内ファイルプレビューでは、JavaScriptが実行されず起動画面のままになる場合があります。iPhoneではWebサーバーに配置したページをSafariで開いてください。縦画面にも対応していますが、横画面の方が都市を見渡しやすくなります。

## 操作

| 操作 | 動作 |
| --- | --- |
| 再生／一時停止 | 10秒のカメラ演出を再生・停止 |
| 最初から | 視点を初期位置に戻して再生 |
| シークバー | 0〜10秒の位置へ移動し、一時停止 |
| ドラッグ／スワイプ | カメラ演出を止め、視点を旋回 |
| ホイール | 接近・後退（PC） |
| 音 ON／OFF | 合成した環境音を切り替え。初期状態はOFF |
| 全画面 | 対応ブラウザーで全画面表示を切り替え |
| Space／R | 再生・停止／最初から再生（PC） |

10秒の演出終了後も、街をドラッグして見回せます。OSの「視差効果を減らす」などの動きを抑える設定が有効な場合、初期表示は全景で停止します。「再生」で演出を開始できます。

## 確認状況

- JavaScriptの構文チェック済み。
- 外部アセット・通信処理への依存がないことをコードで確認済み。
- WebGLを模擬した実行で、都市データ・カメラ行列の有限値、10秒再生、再生し直し、シーク、縦画面の計算を確認済み。
- 実ブラウザーでのGPU描画、iPhone実機での表示・タッチ操作は未検証です。描画速度は端末によって異なります。

3D描画に対応していない場合や初期化に失敗した場合は、画面に案内を表示します。
